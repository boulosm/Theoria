How to build an inventory tracker in Excel

Step-by-step guide to building a reliable Excel inventory tracker with tables, drop-downs, SUMIFS stock on hand and automatic reorder alerts.

By Theoria Analytics8 min readUpdated September 29, 2026

A simple inventory tracker is one of the most useful things you can build in Excel. Done right, it tells you what you have, where it is and what needs reordering, without anyone doing maths by hand. This guide walks through a reliable setup using two tables and a few formulas.

The key idea: don’t type stock quantities in directly. Record every movement (stock in, stock out) and let Excel calculate what’s on hand. You get an automatic history and far fewer mistakes.

Step 1: Create an items table

On a sheet called Items, add these headers: Item ID, Item name, Category, Location, Unit cost, Reorder level. Fill in a few rows, click any cell and press Ctrl + T to turn it into an Excel Table. Under Table Design, rename it tblItems.

Tables expand automatically as you add rows, and formulas can refer to columns by name, which makes everything easier to read and maintain.

Step 2: Create a stock movements table

On a second sheet called Movements, add: Date, Item ID, Type, Quantity, Note. Convert it to a table and name it tblMoves. Every delivery is a row with Type In; every sale or use is a row with Type Out. Record your starting stock as an In row on day one.

Step 3: Add drop-down lists

Drop-downs keep entries consistent, and consistency is what makes the formulas work.

  1. Select the Type column in tblMoves, go to Data › Data Validation, choose List and enter In,Out.
  2. Select the Item ID column, choose List again, and use this source:
=INDIRECT("tblItems[Item ID]")

Data validation can’t reference a table column directly, and wrapping it in INDIRECT gets around that. New items you add will appear in the list automatically.

Step 4: Calculate stock on hand

Back in tblItems, add a column called On hand with this formula:

=SUMIFS(tblMoves[Quantity], tblMoves[Item ID], [@[Item ID]], tblMoves[Type], "In")
 - SUMIFS(tblMoves[Quantity], tblMoves[Item ID], [@[Item ID]], tblMoves[Type], "Out")

It adds up everything that came in for that item and subtracts everything that went out.

Step 5: Flag what needs reordering

Add a Status column:

=IF([@[On hand]]<=0, "Out of stock", IF([@[On hand]]<=[@[Reorder level]], "Reorder", "OK"))

Then select the Status column and use Home › Conditional Formatting › Highlight Cells Rules › Equal To to colour “Reorder” yellow and “Out of stock” red.

Step 6: Add stock value and a summary

Add a Stock value column with =[@[On hand]]*[@[Unit cost]]. Then, on a summary sheet:

Total stock value:   =SUM(tblItems[Stock value])
Items to reorder:    =COUNTIF(tblItems[Status], "Reorder")
Out of stock:        =COUNTIF(tblItems[Status], "Out of stock")

Tips to keep it reliable

  • Never delete movement rows. If something was entered wrong, add a correcting row. Your history stays intact.
  • Do a count now and then. Record any difference as an adjustment row with a note.
  • Protect the formula columns so they don’t get typed over.

When you’ll outgrow the basic version

This setup works well for a single location and a few hundred items. It starts to strain when you need stock across several locations, purchase orders, supplier lead times, barcode scanning or several people entering data at once. That’s when a custom-built tracker pays off.
