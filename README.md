# Theoria Analytics Website

Responsive GitHub-ready static website using the approved teal branding, logo and cover photo.

## Before publishing
Replace the placeholder email, phone number and sample reviews in `index.html`.

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files and the `assets` folder.
3. Open Settings → Pages.
4. Publish from the `main` branch and `/root` directory.

The contact form currently uses `mailto:`. For direct form submissions, connect Formspree, Netlify Forms, HubSpot, Web3Forms or a custom backend.

## Added Project-Based Services

The site now also promotes one-time and custom project support, including:

- Guest lists, invitations and registration tracking
- Recipe, menu and product databases
