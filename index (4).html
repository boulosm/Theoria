What affects the price

Every workbook is different, so here’s what moves a project up or down in price:

  • Number of sheets and functions. A single calculator is quicker to build than a linked system of trackers, summaries and dashboards.
  • Data sources. Typing data in is simple. Pulling in and cleaning exports from other software takes more setup.
  • Automation. Power Query or macros add value (and build time) when you need repeatable, one-click processes.
  • Starting point. Fixing or extending an existing file is often cheaper than starting from scratch, unless the file needs a full rebuild.
  • Timeline. Tell us if you have a deadline and we’ll let you know what’s realistic.

Which package is right for me?

Excel Fix is for an existing workbook that needs repairs or small changes. Starter suits one focused tool, like a calculator, a tracker or a budget. Pro is for multi-sheet workbooks with dashboards and advanced formulas. Business covers complete systems with reporting and automation.

That’s fine. The packages are guides. We’ll quote your project on its own terms.

Not for the work we agreed on. If you ask for something extra partway through, we’ll quote the addition before doing it.
