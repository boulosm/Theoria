What is Power Query in Excel? A plain-English guide

Power Query explained simply: what it does, where to find it in Excel, a real example combining monthly exports, and when to use it instead of formulas or macros.

By Theoria Analytics7 min readUpdated September 29, 2026

Power Query is one of Excel’s most useful features, and one of the least known. If you regularly download data, tidy it up and paste it into a report, Power Query can do that work for you, and repeat it every time with a single click.

What Power Query actually does

Power Query does three things: it gets data (from files, folders, other workbooks, databases and more), transforms it (removing columns, fixing dates, splitting text, removing duplicates) and loads the clean result into a table in your workbook.

The clever part is that it records every step you take. Next month, when you have new data, you don’t repeat anything. You click Refresh All and Power Query replays every step on the new data.

Where to find it

Power Query is built into Excel, with nothing to install. You’ll find it on the Data tab in the Get & Transform Data group, starting with the Get Data button. It’s included in Excel 2016 and later on Windows and in Microsoft 365. Excel for Mac also includes Power Query in Microsoft 365, though a few data sources are Windows-only.

A real example: combining monthly exports

Say your accounting or sales software gives you a CSV export every month, and you want one table with all of them.

  1. Save every monthly export into one folder.
  2. Go to Data › Get Data › From File › From Folder and pick that folder.
  3. Click Combine & Transform Data and choose a sample file.
  4. In the Power Query Editor, remove the columns you don’t need, set the right data types and filter out blank rows.
  5. Click Home › Close & Load. Your combined table appears in a new sheet.

Next month, drop the new file into the folder and click Data › Refresh All. That’s it.

Common things Power Query can fix

  • Dates imported as text, or in the wrong format
  • Extra spaces and inconsistent capitalization
  • Names or codes that need splitting into separate columns
  • Duplicate rows
  • Data laid out across columns (one column per month) that needs to be rows. That’s “unpivoting”.
  • Matching two tables together, like a lookup (called a “merge”)
  • Stacking tables with the same columns (an “append”)

Power Query, formulas or macros?

Best forWatch out for
FormulasLive calculations that update as you typeGet slow and fragile when used to clean large data
Power QueryImporting, cleaning and combining data on a repeatable basisResults update on Refresh, not instantly
Macros (VBA)Custom buttons, file actions, anything Power Query can’t doMust be enabled; harder to edit; don’t run in Excel for the web

In most of our builds, Power Query handles the data and formulas handle the calculations. Macros are used only when they’re truly the best tool.

When Power Query isn’t the answer

For a one-off task on a small table, doing it by hand is often quicker. And if you need results to change instantly as someone types, like in a quote calculator, formulas are the better fit.
